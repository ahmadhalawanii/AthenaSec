# AthenaSec Frontend

## Start-up

`npm ci` - installs the package with the same exact versions that are listed in package-lock.json.
`npm run build` - validates the project and generates the production build.
npm run dev - is used to start a local development server. To run inside a VM and access it from another device on the same network, use the command: `npm run dev -- --host 0.0.0.0`.
